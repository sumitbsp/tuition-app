# CLAUDE.md

## Testing
- Do not open a browser, take screenshots, or run browser/UI tests
  unless I explicitly ask for it in that message.
- I test features manually myself after each change.
- After making changes, only run the type check and build to make sure
  nothing is broken, and report any errors.
- When you finish a feature, give me a short checklist of what to test
  manually (happy path, edge cases, and keyboard/screen reader checks).
- If I ask you to test something, test only that specific thing, then
  go back to these rules.
